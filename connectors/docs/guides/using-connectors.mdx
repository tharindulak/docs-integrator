The [Overview](../concepts/overview.mdx) introduces connectors, connections, actions, and triggers as concepts. This page shows how they come together in practice, once you've picked a connector from the [catalog](../index.mdx).

## Create a connection

Before you can call a connector's actions, you need a connection: a named, reusable configuration holding the credentials and endpoint settings for the external service. You create one from the **Artifacts** view or directly from the node palette while building a flow.

<ThemedImage light="../../assets/img/connectors/using-connectors/add-connection.png" dark="../../assets/img/connectors/using-connectors/add-connection.png" alt="Add Connection panel" />

Fill in the connection initialization form with the connector's specific configuration, such as endpoints, API keys, or OAuth settings.

<ThemedImage light="../../assets/img/connectors/using-connectors/init-connection.png" dark="../../assets/img/connectors/using-connectors/init-connection.png" alt="Connection initialization form" />

See [Connections](https://wso2.com/integration-platform/docs/integrator/develop-and-test/integration-artifacts/supportive-artifacts/connections) for how to add, edit, and reuse connections across an integration, and the [node palette's connection section](https://wso2.com/integration-platform/docs/integrator/editor/canvases/flow-canvas/node-palette#connection) for adding one without leaving the flow you're building.

## Invoke an action

Once a connection exists, it appears in the node palette's **Connections** section. Expand the dropdown of the created connection to see its available actions.

<ThemedImage light="../../assets/img/connectors/using-connectors/connection-node.png" dark="../../assets/img/connectors/using-connectors/connection-node.png" alt="A connection in the node palette's Connections section" />

Select an action and configure its inputs the same way you would any other node.

<ThemedImage light="../../assets/img/connectors/using-connectors/connection-actions.png" dark="../../assets/img/connectors/using-connectors/connection-actions.png" alt="Actions available on a connection" />

See the [node palette's connection actions section](https://wso2.com/integration-platform/docs/integrator/editor/canvases/flow-canvas/node-palette#connection-actions) for the mechanics.

## Handle a trigger

Most connectors are action-only, but a select few (primarily databases, messaging systems, and file storage) also support triggers — inbound events the external service pushes into your integration. See [Kafka](https://wso2.com/integration-platform/docs/integrator/develop-and-test/integration-artifacts/event-driven-integration/kafka) and [CDC (MySQL)](https://wso2.com/integration-platform/docs/integrator/develop-and-test/integration-artifacts/event-driven-integration/cdc-mysql) for two worked examples of setting up a trigger-based flow.
