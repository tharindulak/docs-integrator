This guide walks you through creating an Amazon Redshift cluster and obtaining the JDBC connection URL required to use the AWS Redshift connector.

## Prerequisites

- An active AWS account. If you do not have one, [sign up for a free account](https://aws.amazon.com/free/).

## Step 1: Log in to the AWS Console

Access the [AWS Management Console](https://console.aws.amazon.com/).

## Step 2: Navigate to Amazon Redshift and create a cluster

1. In the AWS Management Console, search for **Redshift** in the services search bar and select it.

   <ThemedImage light="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/create-cluster-1.png" dark="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/create-cluster-1.png" alt="Navigate to Redshift" />

2. Select **Create cluster** to start creating a new cluster.

   <ThemedImage light="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/create-cluster-2.png" dark="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/create-cluster-2.png" alt="Create cluster" />

## Step 3: Configure cluster settings

1. Configure the cluster identifier, database name, and credentials.

   <ThemedImage light="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/basic-configs.png" dark="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/basic-configs.png" alt="Basic configuration" />

2. Configure security groups to control inbound and outbound traffic to your Redshift cluster.

   <ThemedImage light="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/security-configs.png" dark="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/security-configs.png" alt="Security configuration" />

3. Record the username and password you set during cluster configuration — you will need them to authenticate.

   <ThemedImage light="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/credentials.png" dark="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/credentials.png" alt="Record credentials" />

4. Review your settings and select **Create cluster**.

:::warning
Store the admin username and password securely. Do not commit them to source control. Use Ballerina's `configurable` feature and a `Config.toml` file to supply them at runtime.
:::

## Step 4: Wait for cluster availability

1. Monitor the cluster status in the AWS Console until it shows as **Available**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/availability.png" dark="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/availability.png" alt="Cluster availability" />

2. Once the cluster is available, copy the **JDBC URL** from the cluster details. It follows this format:

   ```
   jdbc:redshift://<cluster-endpoint>:5439/<database-name>
   ```

   <ThemedImage light="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/jdbc-url.png" dark="../../../../assets/img/connectors/catalog/database/aws.redshift/setup/jdbc-url.png" alt="Copy JDBC URL" />

:::note
Cluster creation may take several minutes. The JDBC URL is only available after the cluster status becomes **Available**.
:::
