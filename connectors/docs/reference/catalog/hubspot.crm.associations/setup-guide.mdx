This guide walks you through creating a HubSpot developer app and obtaining the OAuth 2.0 credentials required to use the HubSpot CRM Associations connector.

## Prerequisites

- A HubSpot developer account. If you do not have one, [sign up for a free account](https://developers.hubspot.com/get-started).

## Step 1: Log in to the HubSpot developer portal

Log in to your [HubSpot developer account](https://app.hubspot.com/).

## Step 2: Create a developer test account (optional)

Developer test accounts let you test apps and integrations without affecting real HubSpot data.

1. Select **Test accounts** in the left sidebar.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/test_account.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/test_account.png" alt="Test accounts section" />

2. Select **Create developer test account**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/create_test_account.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/create_test_account.png" alt="Create developer test account" />

3. Provide a name for the test account and select **Create**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/create_account.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/create_account.png" alt="Name the test account" />

   The new account appears in the test accounts list.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/test_account_portal.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/test_account_portal.png" alt="Test account portal" />

:::note
Developer test accounts are for development and testing only. Do not use them in production.
:::

## Step 3: Create a HubSpot app

1. Navigate to **Apps** in the left sidebar and select **Create app**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/create_app.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/create_app.png" alt="Create app" />

2. Enter a public app name and an optional description.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/app_name_desc.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/app_name_desc.png" alt="App name and description" />

## Step 4: Set up authentication

1. Go to the **Auth** tab.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/config_auth.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/config_auth.png" alt="Configure authentication" />

2. Under **Scopes**, select **Add new scopes** and add the following scopes:
   - `crm.associations.read`
   - `crm.associations.write`
   - `crm.objects.contacts.read`
   - `crm.objects.contacts.write`
   - `crm.objects.companies.read`
   - `crm.objects.companies.write`
   - `crm.objects.deals.read`
   - `crm.objects.deals.write`

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/add_scopes.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/add_scopes.png" alt="Add scopes" />

3. Under **Redirect URL**, add your redirect URL and select **Create App**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/redirect_url.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/redirect_url.png" alt="Redirect URL" />

## Step 5: Get the client ID and client secret

In the **Auth** tab, copy the **Client ID** and **Client Secret**.

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/client_id_secret.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/client_id_secret.png" alt="Client ID and client secret" />

## Step 6: Get the refresh token

1. Construct the authorization URL:

   ```
   https://app.hubspot.com/oauth/authorize?client_id=<YOUR_CLIENT_ID>&scope=<YOUR_SCOPES>&redirect_uri=<YOUR_REDIRECT_URI>
   ```

2. Open the URL in a browser and select your developer test account to install the app.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/account_select.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.associations/setup/account_select.png" alt="Select account" />

3. Copy the authorization code from the redirect URL.

4. Exchange the code for tokens:

   ```bash
   curl --request POST \
     --url https://api.hubapi.com/oauth/v1/token \
     --header 'content-type: application/x-www-form-urlencoded' \
     --data 'grant_type=authorization_code&code=<CODE>&redirect_uri=<YOUR_REDIRECT_URI>&client_id=<YOUR_CLIENT_ID>&client_secret=<YOUR_CLIENT_SECRET>'
   ```

5. Copy the `refresh_token` from the response.

:::tip
Store the client ID, client secret, and refresh token securely. Use Ballerina's `configurable` feature and a `Config.toml` file to supply them at runtime.
:::
