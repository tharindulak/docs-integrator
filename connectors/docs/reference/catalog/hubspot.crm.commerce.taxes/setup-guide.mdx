This guide walks you through creating a HubSpot developer app and obtaining the OAuth 2.0 credentials required to use the HubSpot CRM Commerce Taxes connector.

## Prerequisites

- A HubSpot developer account. If you do not have one, [sign up for a free account](https://developers.hubspot.com/get-started).

## Step 1: Log in to the HubSpot developer portal

Log in to your [HubSpot developer account](https://app.hubspot.com/).

## Step 2: Create a HubSpot app

1. Select **Create app** from the developer portal.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/build_public_app.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/build_public_app.png" alt="Create public app" />

2. Select **Create app** on the next screen.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/create_app.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/create_app.png" alt="Create app" />

3. Under **App Info**, enter a public app name and an optional logo and description.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/enter_app_details.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/enter_app_details.png" alt="Enter app details" />

4. Go to the **Auth** tab and add your redirect URLs.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/auth_page.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/auth_page.png" alt="Auth page" />

5. Select **Create app**.

## Step 3: Get the client ID and client secret

In the **Auth** tab, copy the **Client ID** and **Client Secret**.

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/client_id_secret.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/client_id_secret.png" alt="Client ID and client secret" />

## Step 4: Get the refresh token

1. In the **Auth** tab, add the required scopes based on the [HubSpot API reference](https://developers.hubspot.com/docs/reference/api):
   - `crm.objects.line_items.read`
   - `crm.objects.line_items.write`
   - `oauth`

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/exmaple_api_reference.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/exmaple_api_reference.png" alt="API reference for scopes" />

2. Under **Sample install URL (OAuth)**, copy the full URL and open it in a browser.

3. Select the account to authorize.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/account_chose.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.commerce.taxes/setup/account_chose.png" alt="Choose account" />

4. Copy the authorization code from the redirect URL.

5. Exchange the code for tokens:

   ```bash
   curl --request POST \
     --url https://api.hubapi.com/oauth/v1/token \
     --header 'content-type: application/x-www-form-urlencoded' \
     --data 'grant_type=authorization_code&code=<CODE>&redirect_uri=<YOUR_REDIRECT_URI>&client_id=<YOUR_CLIENT_ID>&client_secret=<YOUR_CLIENT_SECRET>'
   ```

6. Copy the `refresh_token` from the response.

:::tip
Store the client ID, client secret, and refresh token securely. Use Ballerina's `configurable` feature and a `Config.toml` file to supply them at runtime.
:::
