## What you'll build

Build a WSO2 Integrator automation that connects to HubSpot CRM and creates an engagement note using the `ballerinax/hubspot.crm.engagement.notes` connector. The integration runs as an automation entry point and posts a note with a body and timestamp to HubSpot via a bearer token–authenticated connection.

**Operations used:**
- **Create** : Creates a single CRM engagement note in HubSpot with the specified properties and associations

## Architecture

```mermaid
flowchart LR
    A((User)) --> B[Create Operation]
    B --> C[HubSpot Notes Connector]
    C --> D((HubSpot CRM))
```

## Prerequisites

- A HubSpot account with API access
- A HubSpot Private App bearer token with the `crm.objects.notes.write` scope

## Setting up the HubSpot Notes integration

> **New to WSO2 Integrator?** Follow the [Create a New Integration](https://wso2.com/integration-platform/docs/integrator/develop-and-test/create-workspace) guide to set up your integration first, then return here to add the connector.

## Adding the HubSpot Notes connector

### Step 1: Open the Add Connection palette

Select **+** next to **Connections** in the WSO2 Integrator sidebar to open the Add Connection palette.

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_01_palette.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_01_palette.png" alt="HubSpot Notes connector palette open with search field before any selection" />

### Step 2: Add an automation entry point

Select **+ Add Artifact** → **Automation** → **Create**. An `Automation` entry point named `main` is added under **Entry Points** in the sidebar. The canvas switches to the automation flow view showing a **Start** node and an **Error Handler** block.

## Configuring the HubSpot Notes connection

### Step 3: Fill in the connection parameters

Search for **hubspot**, locate the **Notes** connector (`ballerinax/hubspot.crm.engagement.notes`), and select it to open the **Configure Notes** form. Bind each field to a configurable variable:

- **Config** : HubSpot connection configuration with bearer-token auth using the `hubspotToken` configurable variable
- **Connection Name** : Logical name used to reference this connection throughout the integration

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_02_connection_form.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_02_connection_form.png" alt="HubSpot Notes connection form fully filled with all parameters before saving" />

### Step 4: Save the connection

Select **Save Connection**. The integration canvas displays the `notesClient` connection card.

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_03_connections_list.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_03_connections_list.png" alt="HubSpot Notes Connections panel showing notesClient entry after saving" />

### Step 5: Set actual values for your configurables

In the left panel, select **Configurations**. Set a value for each configurable listed below:

- **hubspotToken** (string) : Your HubSpot Private App bearer token with `crm.objects.notes.write` scope

## Configuring the HubSpot Notes Create operation

### Step 6: Select and configure the Create operation

Select **+** between **Start** and **Error Handler** to open the Node Panel. Expand **Connections → notesClient** to list all available operations.

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_04_operations_panel.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_04_operations_panel.png" alt="HubSpot Notes connection node expanded showing all available operations before selection" />

Select **Create** to open the operation form, then fill in the fields:

- **Payload** : The note payload including `associations` and `properties` (set `hs_note_body` and `hs_timestamp` in expression mode)
- **Result** : Variable name to store the returned `SimplePublicObject`

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_05_operation_filled.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_05_operation_filled.png" alt="HubSpot Notes Create operation configuration filled with all values" />

Select **Save**.

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_06_completed_flow.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagement.notes/hubspot_crm_engagement_notes_screenshot_06_completed_flow.png" alt="Completed HubSpot Notes automation flow" />
