This guide walks you through creating a HubSpot developer app and obtaining the OAuth 2.0 credentials required to use the HubSpot CRM Engagements Calls connector.

## Prerequisites

- A HubSpot developer account. If you do not have one, [sign up for a free account](https://developers.hubspot.com/get-started).

## Step 1: Log in to the HubSpot developer portal

Log in to your [HubSpot developer account](https://app.hubspot.com/).

2. Select **Create developer test account**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/2_create_test_account.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/2_create_test_account.png" alt="Create developer test account" />

3. Provide a name and select **Create**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/3_create_account.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/3_create_account.png" alt="Name the test account" />

2. Enter a public app name and description.

## Step 4: Set up authentication

1. Go to the **Auth** tab.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/7_config_auth.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/7_config_auth.png" alt="Configure authentication" />

2. Scroll down to **Scopes** and select **Add new scopes**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/8_config_scopes.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/8_config_scopes.png" alt="Scopes section" />

3. Add the following scopes:
   - `crm.objects.contacts.read`
   - `crm.objects.contacts.write`

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/9_add_scopes.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/9_add_scopes.png" alt="Add scopes" />

4. Under **Redirect URL**, add your redirect URL and select **Create App**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/10_redirect_url.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/10_redirect_url.png" alt="Redirect URL" />

## Step 5: Get the client ID and client secret

In the **Auth** tab, copy the **Client ID** and **Client Secret**.

<ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/11_client_id_secret.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/11_client_id_secret.png" alt="Client ID and client secret" />

## Step 6: Get the refresh token

1. Construct the authorization URL:

   ```
   https://app.hubspot.com/oauth/authorize?client_id=<YOUR_CLIENT_ID>&scope=<YOUR_SCOPES>&redirect_uri=<YOUR_REDIRECT_URI>
   ```

2. Open the URL in a browser, select your developer test account, and authorize the app.

   <ThemedImage light="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/12-hubspot_auth_config_screen.png" dark="../../../../assets/img/connectors/catalog/crm-sales/hubspot.crm.engagements.calls/setup/12-hubspot_auth_config_screen.png" alt="Auth config screen" />

3. Copy the authorization code from the redirect URL.

4. Exchange the code for tokens:

   ```bash
   curl --request POST \
     --url https://api.hubapi.com/oauth/v1/token \
     --header 'content-type: application/x-www-form-urlencoded' \
     --data 'grant_type=authorization_code&code=<CODE>&redirect_uri=<YOUR_REDIRECT_URI>&client_id=<YOUR_CLIENT_ID>&client_secret=<YOUR_CLIENT_SECRET>'
   ```

5. Copy the `refresh_token` from the response.

:::tip
Store the client ID, client secret, and refresh token securely. Use Ballerina's `configurable` feature and a `Config.toml` file to supply them at runtime.
:::
