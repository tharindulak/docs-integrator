This guide walks you through creating a Mailchimp account, enabling the transactional email feature, and generating a Mandrill API key required to use the Mailchimp Transactional connector.

## Prerequisites

- A Mailchimp account. If you do not have one, [sign up for free](https://login.mailchimp.com/signup/).

## Step 1: Log in to your Mailchimp account

1. Log in to your Mailchimp account at [login.mailchimp.com](https://login.mailchimp.com/).
2. Select your profile icon in the top-right corner to open the account menu.

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-dashboard.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-dashboard.png" alt="Mailchimp dashboard" />

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-menu.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-menu.png" alt="Profile menu" />

## Step 2: Enable transactional email

1. In the account menu, select **Billing**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-billing.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-billing.png" alt="Billing section" />

2. Under **Monthly plans or credits**, select the **Transactional Email Plan** (you can start with the demo plan).

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-transactional-setup.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-transactional-setup.png" alt="Transactional email plan" />

## Step 3: Generate a Mandrill API key

1. Navigate to the **Extras** section and select **API keys**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-api-key-menu.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-api-key-menu.png" alt="Extras section" />

2. Select **Create A Mandrill API Key** (not the regular API key). You are redirected to the MandrillApp dashboard.

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-create-api-key.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-create-api-key.png" alt="Mandrill API key selection" />

3. In the MandrillApp dashboard, select **+ Add API Key** to generate your key.

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-create-mandril-key.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/mailchimp-create-mandril-key.png" alt="MandrillApp dashboard" />

4. Copy the generated API key.

   <ThemedImage light="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/validate-api-key-info.png" dark="../../../../assets/img/connectors/catalog/marketing-social/mailchimp.transactional/setup/validate-api-key-info.png" alt="Copy API key" />

:::warning
Store your Mandrill API key securely. Do not commit it to source control. Use Ballerina's `configurable` feature and a `Config.toml` file to supply it at runtime.
:::
