## What you'll build

Build an integration workflow that connects to an SAP S/4HANA system and retrieves sales order header records. The workflow calls the Sales Order (A2X) API and logs the result as JSON.

**Operations used:**
- **listA_SalesOrders** : Reads sales order headers from the SAP S/4HANA system, returning the first 10 results

## Architecture

```mermaid
flowchart LR
    A((User)) --> B[listA_SalesOrders Operation]
    B --> C[SAP S/4HANA Connector]
    C --> D((SAP S/4HANA))
```

## Prerequisites

- Access to an SAP S/4HANA system with valid credentials and the Sales Order (A2X) API exposed through a communication arrangement (see the [Setup Guide](./setup-guide.mdx))

## Setting up the SAP S/4HANA sales order integration

> **New to WSO2 Integrator?** Follow the [Create a New Integration](https://wso2.com/integration-platform/docs/integrator/develop-and-test/create-workspace) guide to set up your integration first, then return here to add the connector.

## Adding the SAP S/4HANA sales order connector

### Step 1: Open the connector palette and search for the connector

Select **Add Connection** in the WSO2 Integrator sidebar to open the connector palette, then search for `api_sales_order_srv` and select the **Api_sales_order_srv** connector card.

## Configuring the SAP S/4HANA sales order connection

### Step 2: Fill in the connection parameters

Enter the connection parameters, binding each field to a configurable variable:

- **Config** : `ConnectionConfig` record containing basic auth credentials; bind to configurable variables for username and password
- **Hostname** : SAP S/4HANA server hostname; bind to a configurable variable
- **Connection Name** : Set to `apiSalesOrderSrvClient`

<ThemedImage light="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_02_connection_form.png" dark="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_02_connection_form.png" alt="SAP S/4HANA Sales Order connection form fully filled with all parameters before saving" />

### Step 3: Save the connection

Select **Save Connection** to persist the configuration and confirm the connector appears in the Connections panel.

<ThemedImage light="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_03_connection_saved.png" dark="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_03_connection_saved.png" alt="SAP S/4HANA Sales Order Connections panel showing apiSalesOrderSrvClient entry after saving" />

### Step 4: Set actual values for your configurables

1. In the left panel, select **Configurations**.
2. Set a value for each configurable listed below:

- **sapS4HanaHostname** (string) : The hostname of your SAP S/4HANA server
- **sapS4HanaUsername** (string) : Your SAP S/4HANA login username
- **sapS4HanaPassword** (string) : Your SAP S/4HANA login password

## Configuring the SAP S/4HANA sales order listA_SalesOrders operation

### Step 5: Add an automation entry point

Select **Add Artifact**, then select **Automation** from the artifact types and select **Create** to add the automation entry point to the canvas.

### Step 6: Select and configure the listA_SalesOrders operation

1. On the automation canvas, select the **+** button to add a step.
2. Expand the **apiSalesOrderSrvClient** connection under **Connections**.
3. Select **List A Sales Orders** (`listA_SalesOrders`).

<ThemedImage light="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_04_operations.png" dark="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_04_operations.png" alt="SAP S/4HANA Sales Order connection node expanded showing all available operations before selection" />

Configure the operation parameters:

- **$top** : Limit results to the first 10 sales orders
- **$skip** : Start from the beginning of the result set
- **Result** : Variable name to store the response

<ThemedImage light="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_05_operation_form.png" dark="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_05_operation_form.png" alt="SAP S/4HANA Sales Order listA_SalesOrders operation configuration filled with all values" />

Select **Save** to add the operation to the flow, then add a **Log Info** step that logs `result.toJsonString()`.

<ThemedImage light="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_06_completed_flow.png" dark="../../../../assets/img/connectors/catalog/erp-business/sap.s4hana.api_sales_order_srv/sap_s4hana_apisalesordersrv_screenshot_06_completed_flow.png" alt="Completed SAP S/4HANA Sales Order automation flow" />
