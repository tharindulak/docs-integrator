This guide walks you through creating a Slack application and obtaining the OAuth token required to use the Slack connector.

## Step 1: Sign in to Slack

Sign in to [Slack](https://slack.com/). If you don't have an account, [create one here](https://slack.com/get-started#/createnew).

<ThemedImage light="../../../../assets/img/connectors/catalog/communication/slack/setup/sign-in.png" dark="../../../../assets/img/connectors/catalog/communication/slack/setup/sign-in.png" alt="Sign-in page" />

## Step 2: Create a new Slack application

1. Navigate to your apps in the [Slack API](https://api.slack.com/) and create a new Slack app.

   <ThemedImage light="../../../../assets/img/connectors/catalog/communication/slack/setup/create-slack-app.png" dark="../../../../assets/img/connectors/catalog/communication/slack/setup/create-slack-app.png" alt="Create Slack app" />

2. Provide an app name and select your workspace.

   <ThemedImage light="../../../../assets/img/connectors/catalog/communication/slack/setup/create-slack-app-2.png" dark="../../../../assets/img/connectors/catalog/communication/slack/setup/create-slack-app-2.png" alt="App name and workspace" />

3. Select **Create App**.

## Step 3: Add scopes to the token

1. Under **Add Features and Functionality**, select **Permissions** to set the token scopes.

   <ThemedImage light="../../../../assets/img/connectors/catalog/communication/slack/setup/add-features.png" dark="../../../../assets/img/connectors/catalog/communication/slack/setup/add-features.png" alt="Add features and functionality" />

2. In the **User Token Scopes** section, add the required scopes.

   <ThemedImage light="../../../../assets/img/connectors/catalog/communication/slack/setup/token-permissions.png" dark="../../../../assets/img/connectors/catalog/communication/slack/setup/token-permissions.png" alt="User token scopes" />

3. Select **Install to Workspace**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/communication/slack/setup/install-workspace.jpg" dark="../../../../assets/img/connectors/catalog/communication/slack/setup/install-workspace.jpg" alt="Install to workspace" />

4. Copy the OAuth token generated upon installation.

   <ThemedImage light="../../../../assets/img/connectors/catalog/communication/slack/setup/copy-token.jpg" dark="../../../../assets/img/connectors/catalog/communication/slack/setup/copy-token.jpg" alt="Copy token" />
