This guide walks you through obtaining a Trello API key and token required to use the Trello connector.

## Prerequisites

- An active Trello account. If you do not have one, [sign up for free](https://trello.com/signup).

## Step 1: Create a Power-Up in the admin portal

1. Log in to your Trello account.
2. Navigate to the [Trello Power-Ups admin portal](https://trello.com/power-ups/admin).

   <ThemedImage light="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-powerups.png" dark="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-powerups.png" alt="Power-Ups admin portal" />

3. Select **New** to create a new Power-Up.
4. Fill in the required fields (name, workspace, and a placeholder iframe connector URL) and select **Create**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-form.png" dark="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-form.png" alt="Create Power-Up form" />

## Step 2: Generate an API key

1. After creation, select the Power-Up name to open its settings.
2. Select the **API Key** tab.

   <ThemedImage light="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-generateKey.png" dark="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-generateKey.png" alt="Navigate to API key tab" />

3. Select **Generate a new API Key** and copy the displayed **API Key**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-key.png" dark="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-key.png" alt="API key displayed" />

:::note
If you previously generated a key at `trello.com/app-key`, that flow has been replaced by the Power-Up Admin portal.
:::

## Step 3: Generate an API token

1. On the same API Key page, select the **Token** link next to your API key.

   <ThemedImage light="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-permission.png" dark="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-permission.png" alt="Token link on API key page" />

2. Review the permissions requested and select **Allow**.
3. Copy the generated **Token**.

   <ThemedImage light="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-token.png" dark="../../../../assets/img/connectors/catalog/productivity-collaboration/trello/setup/trello-token.png" alt="Copy the generated token" />

:::tip
Store the API Key and Token securely. Do not commit them to source control. Use Ballerina's `configurable` feature and a `Config.toml` file to supply them at runtime.
:::

:::warning
The token grants access to your Trello account. Treat it like a password and revoke it if compromised.
:::
