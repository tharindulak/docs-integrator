WSO2 Cloud - Integration Platform is a managed cloud environment for running integrations developed with WSO2 Integrator. Once you push an integration to the cloud, the console gives you full control over how it runs: you can track build and deployment status, promote integrations across environments, configure runtime values and security, monitor logs and metrics, and control who has access, all without managing infrastructure.

## Management areas

| Area | Description |
|---|---|
| [Integrations](./integrations.mdx) | View build and deployment status, and manage the integration lifecycle, including redeployment, schedules, and stopping. |
| [Projects](./projects.mdx) | Create, view, edit, and remove projects within your organization. |
| [CI/CD](./cicd/index.mdx) | Connect a Git repository so that every commit triggers a build and deployment automatically. Configure deployment pipelines to control how integrations move from development to production. |
| [Environments](./environments/index.mdx) | Promote integrations across environments with optional approval gates. Override configuration values at each stage without changing integration code. |
| [Configurations](./configurations/index.mdx) | Set runtime values and secrets, control endpoint visibility and security, configure build behavior, and tune autoscaling per environment. |
| [Observability](./observability/index.mdx) | Monitor request throughput, latencies, and resource usage. Search and filter runtime logs, and configure anomaly detection alerts. |
| [Users and access](./users-and-access/index.mdx) | Manage user groups and roles, control access at the organization or project level, and configure enterprise login with an external identity provider. |
