A project is the top-level container for your integrations on WSO2 Cloud - Integration Platform. This page explains how to view your projects, edit their details, and remove them when they are no longer needed. To create a project, see [Create a project](../../guides/develop-and-test/create-workspace/create-a-project.mdx). To bring one in from a Git repository, see [Import a project](../../guides/develop-and-test/create-workspace/import-a-project.mdx).

## View projects

Click **Organization** in the top navigation to open the organization overview. The overview lists all projects in your organization. By default a project named **Default** is automatically created on first sign-up.

## Edit a project

1. From the project home, go to **Admin** > **Settings**.
2. Update the **Name** or **Description** as needed by clicking the respective fields.

    <ThemedImage light="../../../assets/img/manage/cloud/projects/manage-project.png" dark="../../../assets/img/manage/cloud/projects/manage-project.png" alt="Project Overview" />

3. Save your changes.

## Remove a project

:::warning
A project cannot be deleted without deleting all its integrations first.
:::

:::danger
Removing a project is permanent. All history within the project is deleted and cannot be recovered.
:::

1. From the project home, go to **Admin** > **Settings**.
2. Click **Remove Project** on the right side of the page.

    <ThemedImage light="../../../assets/img/manage/cloud/projects/delete-project-button.png" dark="../../../assets/img/manage/cloud/projects/delete-project-button.png" alt="Remove Project button on the project settings page" />

3. Enter the project name to confirm, then click **Delete**.

    <ThemedImage light="../../../assets/img/manage/cloud/projects/delete-project-confirm.png" dark="../../../assets/img/manage/cloud/projects/delete-project-confirm.png" alt="Confirmation dialog for removing a project" />

The project and all its contents are permanently deleted.
