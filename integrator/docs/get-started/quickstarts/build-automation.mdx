**Time:** Under 10 minutes

**What you'll build:** An automation that prints <code>Hello World</code> to the terminal when it runs.

<p style={{textAlign: 'justify'}}>
An automation runs your integration logic without requiring an external request, either on demand or on a schedule. Automations are useful for tasks such as data synchronization, report generation, and routine maintenance. This quick start walks you through the full process: adding an automation artifact, building the logic in the visual designer, running it, and reviewing scheduling options for production.
</p>

## Prerequisites

A working WSO2 Integrator environment.

:::info[Local setup]

Install and launch WSO2 Integrator on your machine. See [Local setup](../setup/index.mdx).

:::

:::info[WSO2 Cloud Account]

For AI assisted development and WSO2 Cloud deployments. See [WSO2 Cloud Account](https://wso2.com/integration-platform/docs/saas/get-started/setup).

:::



## Step 1: Create the integration

:::info[Note]
If you're using the cloud editor, a project is already open, so you can skip this step and go directly to [Step 2: Add an automation artifact](#step-2-add-an-automation-artifact).
:::

1. Open WSO2 Integrator.

2. Click **Create** in the **Create a Project** card.

   <ThemedImage light="../../../assets/img/get-started/build-automation/wso2-integrator.png" dark="../../../assets/img/get-started/build-automation/wso2-integrator.png" alt="WSO2 Integrator home screen with the Create a Project card" />

3. Set **Project Name** to `automation-quickstart`.

4. Set **Integration Name** to `HelloWorldAutomation`.

5. Click **Create**.

   <ThemedImage light="../../../assets/img/get-started/build-automation/create-project.png" dark="../../../assets/img/get-started/build-automation/create-project.png" alt="Create a Project form with Project name set to automation-quickstart and Integration name set to HelloWorldAutomation" />


## Step 2: Add an automation artifact

1. Select your integration from the project overview canvas.

2. In the design view, click **Add Artifact Manually**.

   <ThemedImage light="../../../assets/img/get-started/build-automation/add-artifact.png" dark="../../../assets/img/get-started/build-automation/add-artifact.png" alt="Integration design view with the Add Artifact manually button highlighted" />

3. Select **Automation** under **Automation**.

   <ThemedImage light="../../../assets/img/get-started/build-automation/select-automation.png" dark="../../../assets/img/get-started/build-automation/select-automation.png" alt="Artifacts page with Automation highlighted under Automation" />

4. Click **Create**.

   <ThemedImage light="../../../assets/img/get-started/build-automation/create-automation.png" dark="../../../assets/img/get-started/build-automation/create-automation.png" alt="Create New Automation form with the Create button" />


## Step 3: Add logic

1. Click **+** below the **Start** node to open the node panel.

2. Select **Call Function** under **Statement**.

   <ThemedImage light="../../../assets/img/get-started/build-automation/call-function-selection.png" dark="../../../assets/img/get-started/build-automation/call-function-selection.png" alt="Node panel with Call Function highlighted under Statement" />

3. Search for `print` in the functions panel.

4. In the search results, go to the **Standard Library** section and select the **print** function under **io**.

   <ThemedImage light="../../../assets/img/get-started/build-automation/select-print.png" dark="../../../assets/img/get-started/build-automation/select-print.png" alt="Functions list with print highlighted under io" />

5. Click **Initialize Array** for the **Values** parameter.

   <ThemedImage light="../../../assets/img/get-started/build-automation/select-initialize-array.png" dark="../../../assets/img/get-started/build-automation/select-initialize-array.png" alt="io:print panel with the Initialize Array button highlighted under Values" />

6. Set **Values** to `"Hello World"` and select **Save**.

   <ThemedImage light="../../../assets/img/get-started/build-automation/set-value.png" dark="../../../assets/img/get-started/build-automation/set-value.png" alt="io:print panel with Values set to Hello World" />


## Step 4: Run and test

1. Click **Run**.

2. Confirm the terminal output contains `Hello World`.

   <ThemedImage light="../../../assets/img/get-started/build-automation/run-and-test-light.gif" dark="../../../assets/img/get-started/build-automation/run-and-test-light.gif" alt="Running the automation and seeing the Hello World output in the terminal" />

## Source code

<details>
<summary>View the generated Ballerina code</summary>

The steps above generate the following complete, runnable Ballerina program:

```ballerina
import ballerina/io;
import ballerina/log;

public function main() returns error? {
   do {
       io:print("Hello World");
   } on fail error e {
       log:printError("Error occurred", 'error = e);
       return e;
   }
}
```

</details>


## Scheduling automations

Periodic invocation is configured in an external system once the automation is deployed. Available options include:

- **Cron job**: schedule the automation from a `cron` entry on a Unix or Linux host.
- **Kubernetes**: define a `CronJob` resource to run the automation on a recurring schedule.
- **VM**: use a host scheduler such as Windows Task Scheduler or `systemd` timers.
- **WSO2 Integration Platform**: configure the schedule in the WSO2 Integration Platform when the integration is pushed to the cloud.
