**Time:** Under 10 minutes

**What you'll build:** An HTTP service that listens on <code>/hello/greeting</code>, calls an external API, and returns the response to the caller.

<p style={{textAlign: 'justify'}}>
An HTTP service exposes your integration logic as a REST endpoint. This quick start shows the full cycle: create a service, add a resource, connect to an external API, and test it using the Try-It/Test panel in WSO2 Integrator.
</p>

## Prerequisites

A working WSO2 Integrator environment.

:::info[Local setup]

Install and launch WSO2 Integrator on your machine. See [Local setup](../setup/index.mdx).

:::

:::info[WSO2 Cloud Account]

For AI assisted development and WSO2 Cloud deployments. See [WSO2 Cloud Account](https://wso2.com/integration-platform/docs/saas/get-started/setup).

:::



## Step 1: Create the integration

:::info[Note]
If you're using the cloud editor, a project is already open, so you can skip this step and go directly to [Step 2: Add an HTTP service](#step-2-add-an-http-service).
:::

1. Open WSO2 Integrator.

2. Click **Create** in the **Create a Project** card.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/wso2-integrator.png" dark="../../../assets/img/get-started/build-api-integration/wso2-integrator.png" alt="WSO2 Integrator home screen with the Create a Project card" />

3. Set **Project Name** to `integration-as-api`.

4. Set **Integration Name** to `HelloWorldAPI`.

5. Click **Create**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/create-project.png" dark="../../../assets/img/get-started/build-api-integration/create-project.png" alt="Create a Project form with Project name set to integration-as-api and Integration name set to HelloWorldAPI" />


## Step 2: Add an HTTP service

1. Select your integration from the project overview canvas.

2. In the design view, click **Add Artifact Manually**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/add-artifact.png" dark="../../../assets/img/get-started/build-api-integration/add-artifact.png" alt="Integration design view with the Add Artifact manually button highlighted" />

3. Select **HTTP Service** under **Integration as API**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/select-http.png" dark="../../../assets/img/get-started/build-api-integration/select-http.png" alt="Artifacts page with HTTP Service highlighted under Integration as API" />

4. Keep **Service Contract** as **Design From Scratch**.

5. Set **Service Base Path** to `/hello`.

6. Click **Create**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/set-path.png" dark="../../../assets/img/get-started/build-api-integration/set-path.png" alt="Create HTTP Service form with Service Base Path set to /hello" />

## Step 3: Add a resource

1. In the HTTP service design view, click **+ Add Resource**.

2. Select **GET**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/select-get.png" dark="../../../assets/img/get-started/build-api-integration/select-get.png" alt="Select HTTP Method to Add panel with GET highlighted" />

3. Set **Resource path** to `greeting`.

4. Click **Save**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/set-resource-path.png" dark="../../../assets/img/get-started/build-api-integration/set-resource-path.png" alt="New Resource Configuration panel with Resource Path set to greeting" />


## Step 4: Connect to an external API

1. Click **+** inside the resource flow.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/select-plus.png" dark="../../../assets/img/get-started/build-api-integration/select-plus.png" alt="Resource flow with the add node button highlighted" />

2. Click **Add Connection** under **Connections**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/add-connection.png" dark="../../../assets/img/get-started/build-api-integration/add-connection.png" alt="Node panel with Add Connection highlighted" />

3. Select **HTTP** under **Pre-built Connectors**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/add-connection-http.png" dark="../../../assets/img/get-started/build-api-integration/add-connection-http.png" alt="Add Connection dialog with the HTTP connector highlighted" />

4. The **Configure HTTP** form opens. Set **Url** to:

   ```text
   https://apis.wso2.com/zvdz/mi-qsg/v1.0
   ```
   <ThemedImage light="../../../assets/img/get-started/build-api-integration/set-url.png" dark="../../../assets/img/get-started/build-api-integration/set-url.png" alt="Configure HTTP form with Url set" />

5. Scroll to the bottom of the form. Set **Connection Name** to `externalApi`.

6. Click **Save Connection**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/set-connection-name.png" dark="../../../assets/img/get-started/build-api-integration/set-connection-name.png" alt="Configure HTTP form with Connection Name set to externalApi" />

## Step 5: Call the external API

1. Click **+** inside the resource flow.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/select-plus.png" dark="../../../assets/img/get-started/build-api-integration/select-plus.png" alt="Resource flow with the add node button highlighted" />

2. Select **externalApi**.

3. Select **Get**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/select-externalapi.png" dark="../../../assets/img/get-started/build-api-integration/select-externalapi.png" alt="Node panel with the externalApi connection and its Get action highlighted" />

4. Set **Path** to `/`.

5. Set **Result** to `response`.

6. Set **Target Type** to `json`.

7. Click **Save**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/externalapi-get-form.png" dark="../../../assets/img/get-started/build-api-integration/externalapi-get-form.png" alt="externalApi get form with Path, Result, and Target Type set" />


## Step 6: Return the response

1. Click **+** inside the resource flow after the external API call node we just added.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/select-plus-after-call.png" dark="../../../assets/img/get-started/build-api-integration/select-plus-after-call.png" alt="Resource flow with the add node button highlighted after the http:get node" />

2. Select **Return** under **Control**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/select-return.png" dark="../../../assets/img/get-started/build-api-integration/select-return.png" alt="Node panel with Return highlighted under Control" />

3. In the **Expression** field, select `response` from the variables.

4. Click **Save**.

   <ThemedImage light="../../../assets/img/get-started/build-api-integration/set-expression.png" dark="../../../assets/img/get-started/build-api-integration/set-expression.png" alt="Return panel with Expression set to response" />


## Step 7: Run and test

1. Click **Run**.

2. Click **Test** in the confirmation dialog.

3. Click **Execute Cell**.

4. Confirm the response shows `200 OK` with a `Hello World` body.


   <ThemedImage light="../../../assets/img/get-started/build-api-integration/run-and-test.gif" dark="../../../assets/img/get-started/build-api-integration/run-and-test.gif" alt="Running the integration and testing it with the Try It panel showing a 200 OK response" />

## Step 8: Deploy to WSO2 Cloud

Deploy your integration to WSO2 Cloud - Integration Platform in any of the following ways:

- If you're using the cloud editor, see [Save and deploy](../../deploy-and-operate/deploy-and-run/deploy-to-wso2-cloud/deploy-from-cloud-editor.mdx#save-and-deploy).
- If you're using WSO2 Integrator on your machine, see [Deploy from WSO2 Integrator](../../deploy-and-operate/deploy-and-run/deploy-to-wso2-cloud/push-from-ide.mdx).

## Source code

<details>
<summary>View the generated Ballerina code</summary>

The steps above generate the following complete, runnable Ballerina program:

```ballerina
import ballerina/http;

listener http:Listener httpDefaultListener = http:getDefaultListener();

final http:Client externalApi = check new ("https://apis.wso2.com/zvdz/mi-qsg/v1.0");

service /hello on httpDefaultListener {


   resource function get greeting() returns json|error {
       do {
           json response = check externalApi->get("/");
           return response;
       } on fail error err {
           // handle error
           return error("unhandled error", err);
       }
   }
}
```

</details>
