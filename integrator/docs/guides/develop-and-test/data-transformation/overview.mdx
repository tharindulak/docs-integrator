Most integrations spend as much time reshaping data as they do moving it. Use the visual **Data Mapper** to wire fields between typed values, and reach for the format-specific pages below whenever you need to parse, construct, or stream a particular file format.

## [Data Mapper](../integration-artifacts/supportive-artifacts/data-mapper/index.mdx)

Visually map fields between typed values, with support for arrays, sub-mappings, reusable functions, and AI-assisted mapping.

## [JSON](./json.mdx)

Parse, construct, transform, and validate JSON data.

## [XML](./xml.mdx)

Parse, construct, transform, and validate XML data.

## [CSV &amp; Flat File](./csv-flat-file.mdx)

Parse, transform, and write CSV and flat file data.

## [XLSX](./xlsx.mdx)

Parse, transform, and write Microsoft Excel (XLSX) data.

## [EDI](./edi.mdx)

Parse, transform, and generate EDI documents.

## [PDF](./pdf.mdx)

Extract text, convert pages to images, and render HTML to PDF.

## [Template Rendering](./freemarker.mdx)

Render text, HTML, YAML, and other formats from FreeMarker templates.

## [ZIP Archives](./zip.mdx)

Create, inspect, and safely extract ZIP archives.

## [YAML &amp; TOML](./yaml-toml.mdx)

Parse, construct, and transform YAML and TOML data.
