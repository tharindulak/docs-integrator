This section covers the Develop and Test phase of the [integration lifecycle](../../index.mdx#from-development-to-production): building integrations in the WSO2 Integrator editor before anything ships. We assume you're already familiar with the editor's surfaces from the [Editor Tour](../editor/index.mdx).

:::tip
Start building your integration by prompting [WSO2 Integrator Copilot](../editor/copilot/overview.mdx) to generate a first working version of your integration flow, refine it on the visual designer, and drop into Ballerina pro-code only when you need more precise control; everything stays in sync throughout.
:::
