WSO2 Integrator lets you build AI-powered integrations, including direct LLM calls, AI agents, RAG pipelines, MCP servers, natural functions, and voice agents.

## [AI Building Blocks](./ai-building-blocks/overview.mdx)

The shared connections and stores every AI feature is built from: model providers, embedding providers, vector stores, knowledge bases, chunkers, and data loaders.

## [Direct LLMs](./direct-llm/index.mdx)

The simplest AI block. Add a generate node to a flow, write a prompt, and bind the response to a typed value in a single round-trip.

## [AI Agents](./agents/overview.mdx)

Autonomous LLM-driven agents that reason over a system prompt, call tools, and keep memory across turns. Covers reusable definitions, multi-agent systems, gated tools, observability, and evaluations.

## [Retrieval-Augmented Generation (RAG)](./rag/overview.mdx)

Ground LLM responses in your own documents. Ingest documents into a knowledge base, then retrieve the relevant chunks at query time and inject them into the prompt.

## [Model Context Protocol (MCP)](./mcp/overview.mdx)

Expose a service as MCP tools for AI assistants, or use tools from external MCP servers in your agents.

## [Natural Functions](./natural-functions/index.mdx)

Experimental. Write the function body in plain English. The LLM returns a value that conforms to your declared return type.

## [Voice Agent](./voice-agent/index.mdx)

Expose an AI agent over a voice channel. WSO2 Cloud handles speech-to-text and text-to-speech, so your service works only with text.
