Reusable enterprise integration patterns you can apply across projects, each shown as both a Visual Designer flow and the equivalent Ballerina code.

- **[Message](./message.mdx)** -- Package business data and metadata for transmission through a message channel
- **[Message Filter](./message-filter.mdx)** -- Route only messages that match a condition
- **[Content Based Routing](./content-based-routing.mdx)** -- Route messages by inspecting their content
- **[Channel Adapter](./channel-adapter.mdx)** -- Connect applications, services, or broker channels to an integration flow
- **[Message Dispatcher](./message-dispatcher.mdx)** -- Distribute messages from a channel across a pool of consumers
- **[Message Mapper](./message-mapper.mdx)** -- Transform a message from one structure to another
- **[Polling Consumer](./polling-consumer.mdx)** -- Fetch messages from a channel on a schedule instead of waiting for a push
- **[Selective Consumer](./selective-consumer.mdx)** -- Filter which messages a consumer receives from a channel
- **[Service Activator](./service-activator.mdx)** -- Connect a message channel to a service so it can be invoked from an integration flow
