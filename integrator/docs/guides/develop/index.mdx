This section is the handbook for building integrations on your local machine with WSO2 Integrator. Use the visual designer or write Ballerina pro-code — the two stay in sync — and look up the specific task you need: create a service, transform a payload, run a test, profile a hot path.

:::tip[Where Develop ends]
If your code still lives on your machine, you're in **Develop**. Once you push it somewhere else, move to [Deploy and operate](../../deploy-and-operate/deploy/index.mdx).
:::

:::info[AI split]
Tools that help **you** code faster (Copilot, AI test generation, AI-assisted data mapping) live here. Building **AI-powered** integrations (agents, RAG, MCP) belongs in [GenAI](../ai-integrations/index.mdx).
:::
